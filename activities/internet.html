Internet

It is a global network of different connected computers.

Web

It is a system of different websites on the internet.

Difference between Internet and Web

Internet is a network and Web is a service on the internet.

ASCII and Unicode

ASCII is a basic code of letters and symbols, Unicode is code of characters from all languages.

UTF-8

It is a way to store unicode characters.

URL

It is the address of a website.

Domain name

It is a simple name for websites.

HTTP

It is a protocol used to transfer webpages.

HTTPS

It is a version of http to encrypt data.

IP address

It is a numerical identifier assigned to a device.

DNS

It translates domain names to IP address.

W3C Recommendations

They are official rules for the web.

XML

It is a way to store data.

XHTML

It is a more strict version of html.

HTML

The language used to make web pages.

HTML5

The latest version of html.
