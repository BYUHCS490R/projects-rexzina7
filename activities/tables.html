Why don't we use the border attribute?

The border attribute is not used because it is outdated in modern HTML. Instead, we use CSS to style tables because it separates the design from the structure of the webpage.

What is the easiest way to color every other row a different color?

The easiest way is to use CSS with the selector. It allows us to automatically style every other row without adding extra code to each row.
